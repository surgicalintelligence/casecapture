# CaseCapture

A private, on-device surgical case log for medical students, residents and fellows, and attendings.
Dictate a case, get suggested CPT and ICD-10 codes, keep a running log, and export it as a CSV.

**Open the app:** https://surgicalintelligence.github.io/casecapture/
To install: on Android, open it in Chrome and tap ⋮ > Install app (or Add to Home screen). On iPhone, tap Share > Add to Home Screen.

- Everything stays on your device. The app makes no network calls and has no accounts.
- Never enter patient identifiers. The app removes the ones it recognizes, but it cannot catch everything.
- Code suggestions are a starting point; final codes must match your operative note and payer rules.
- CPT codes and descriptions are copyright American Medical Association.
